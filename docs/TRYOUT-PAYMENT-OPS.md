# SOP ringkas pembayaran TO Tutorin tanpa payment gateway

1. Admin menetapkan harga, rekening penerima, nama pemilik rekening, dan periode pendaftaran pada CMS.
2. Peserta mendaftar di website dan menerima nomor pendaftaran.
3. Peserta transfer lalu mengirim konfirmasi WhatsApp yang memuat ID pendaftaran, nominal, waktu transfer, dan nama pengirim.
4. Admin mencocokkan data tersebut dengan mutasi rekening. Jangan menerima screenshot saja sebagai konfirmasi final.
5. Admin membuka CMS > Pendaftar Tryout, mencari ID peserta, lalu menekan **Verifikasi & setujui**.
6. Kode akses terbit otomatis dan tampil di dashboard peserta.
7. Jika transaksi belum cocok, admin jangan menyetujui. Hubungi peserta atau tolak dengan catatan.

Untuk mengurangi kesalahan, sebaiknya gunakan rekening khusus Tutorin. Nominal kode unik transfer dapat dipertimbangkan nanti, tetapi tidak wajib dan harus diuji terhadap biaya bank serta nominal yang dibayarkan peserta.
